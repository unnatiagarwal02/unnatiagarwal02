## Projects

### [PubMed RAG Assistant](https://github.com/unnatiagarwal02/pubmed-rag-assistant)
Answers questions about brain tumor MRI research from about 200 PubMed abstracts. Every finding is cited by PMID, and a guardrail flags cited PMIDs that were never retrieved, numbers that appear in no passage, and claims an LLM judge finds unsupported. Served through FastAPI with a small React front end.

`Python` `LangChain` `ChromaDB` `sentence-transformers` `FastAPI`
